# Сборка Инсталлера (Installer Build)

Эта директория содержит скрипт установки и артефакты сборки для системы MidasCore.

## install.sh

Скрипт `install.sh` является основным способом развертывания всей системы на чистой машине с Linux.

### Предварительные требования
*   ОС Linux (рекомендуется Ubuntu/Debian).
*   Права root (скрипт повышает привилегии с помощью `sudo`).
*   Доступ в Интернет для загрузки бинарных файлов и образов.

### Что он делает

1.  **Подготовка системы**: Устанавливает зависимости (`k3s`, `helm`, `zip`, `jq`).
2.  **Операторы**: Разворачивает операторы Strimzi (Kafka), Altinity (ClickHouse) и Prometheus.
3.  **Инфраструктура**: Разворачивает кластеры Kafka и ClickHouse.
4.  **Сеть**: Устанавливает Envoy Gateway и Cert Manager.
5.  **Приложение**: Разворачивает микросервисы Midas, используя чарты `MidasCore`.
6.  **Конфигурация**:
    *   Создает базу данных и таблицы ClickHouse.
    *   Настраивает параметры ядра системы (`sysctl`).
    *   Генерирует комплекты клиентских сертификатов.
    *   Создает начального пользователя-администратора.

### Использование

```bash
export MIDAS_VERSION="v1.0.0" # Установите желаемый тег версии
./install.sh
```

### Переменные окружения

* `MIDAS_ENABLE_ATLAS` (`true/false`, по умолчанию `false`): включает установку Atlas Operator и ресурс `AtlasSchema`.
* `MIDAS_ATLAS_TOKEN`: обязателен, если `MIDAS_ENABLE_ATLAS=true`. Передается в Atlas Operator через Kubernetes Secret `atlas-token-secret`.
* `MIDAS_EXTERNAL_IP`: принудительно задает внешний IP для Gateway/Frontend ссылок. Рекомендуется для multi-node кластеров.

Если Atlas отключен, схема ClickHouse применяется инсталлером напрямую через `clickhouse-client`, поэтому установка не зависит от Atlas Cloud.

### Источник Helm-чартов

Инсталлер сначала ищет локальные чарты в репозитории:

* `MidasCore/KafkaStrimzi`
* `MidasCore/ClickhouseAltiniti`
* `MidasCore/LoggerServices`

Если локальный чарт найден, используется он (без `--version`), иначе инсталлер использует удалённый репозиторий `midas-edge/*` с версией `CHART_VERSION`.

### Вывод
По завершении скрипт выводит:
*   URL Grafana и учетные данные.
*   URL Фронтенда.
*   Учетные данные начального администратора (сохраняются в `admin_info.json`).
*   Расположение комплекта клиентских сертификатов.
