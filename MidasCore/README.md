# Инфраструктура Midas Core

Эта директория содержит Helm-чарты, используемые для развертывания системы MidasCore и ее зависимостей.

## Структура

*   `LoggerServices/`: Основной чарт приложения, содержащий развертывания для всех микросервисов (Gateway, Event, Analyse и т.д.).
*   `ClickhouseAltiniti/`: Чарт для развертывания кластера ClickHouse с использованием Altinity Operator.
*   `KafkaStrimzi/`: Чарт для развертывания кластера Kafka с использованием Strimzi Operator.

## Конфигурация

Основной файл конфигурации для сервисов приложения — `LoggerServices/values.yaml`. Он управляет:
*   Репозиториями образов и тегами.
*   Количеством реплик и автошасштабированием (HPA/VPA).
*   Портами сервисов и DNS именами.
*   Лимитами ресурсов (CPU/Memory).
*   Настройками персистентности (PVC).

## Развертывание

Эти чарты обычно разворачиваются с помощью скрипта `install.sh`, расположенного в `InstallerBuild/`. Однако их можно установить вручную, используя команду `helm upgrade --install`.
